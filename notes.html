  • <p> tag is used to define a paragraph
  • <br> tag is used to end a line of text and start a new line
  • <img> tag is used to add an image to your page which includes the arguments such as source, alt, width and height
  • <ul> tag is used in combination with the <li> tag to create an unordered list
  • <blockquote> tag is used to punch out a quotation
